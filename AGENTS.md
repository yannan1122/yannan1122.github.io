# Repository Collaboration Rules

- This repository is a GitHub Pages academic homepage.
- After completing and verifying a requested modification, commit the change with a Conventional Commit message and push it to `origin/main` by default.
- If the user explicitly requests local-only work or says not to push, do not push until they give permission.
- Keep the homepage content grounded in the user's supplied CV and assets; do not copy reference-site personal data.
- Do not commit local dependency caches such as `.bundle/`, `vendor/bundle/`, or generated `_site/` output.
